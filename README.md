# cinnamon-store

Desktop themes for Cinnamon on Linux Mint, with matching artwork.

| Theme | Appearance | Package |
| --- | --- | --- |
| GNU-Darwin Aqua | Blue Aqua-inspired controls and a matching original GD wallpaper | [Preview and installation](themes/GNU-Darwin%20Aqua/README.md) |
| GNU-Darwin Workstation | Gray workstation controls, dark borders and a black desktop | [Preview and installation](themes/GNU-Darwin%20Workstation/README.md) |

Each package contains Cinnamon shell styling, GTK 2/3/4 controls, Metacity window borders, a wallpaper and a menu logo. Install and select the theme manually using its README. Existing same-name installations must be backed up before replacement.

The previews use stock Cinnamon applets and the system Adwaita icons. Panel arrangement, icon and cursor themes, fonts, application adapters, terminal setups, Island/Eww and boot/login themes are separate components. The packages do not execute installers or alter session settings.

Validation records in each package describe the exact shipped files, tested environment and scope. Desktop package acceptance does not certify the full workstation setup or boot/login behavior. Other candidates remain in development until their package checks and artwork provenance are complete.

Theme code retains its original GPL notices. Artwork has its own component terms; see each package's `SOURCE-NOTICES.md` and artwork notices. This repository is an independent theme collection and is not an official Cinnamon Spices listing.
