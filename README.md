# cinnamon-store

Desktop themes for Cinnamon on Linux Mint, with matching artwork.

| Theme | Appearance | Package |
| --- | --- | --- |
| GNU-Darwin Aqua | Snow Leopard silver chrome, blue Aqua controls and a reflective glass dock with running lights and Trash | [Preview and installation](themes/GNU-Darwin%20Aqua/README.md) |
| GNU-Darwin Workstation | GNU-Darwin scientific workstation desktop with flat gray controls, square bevels and slate titles | [Preview and installation](themes/GNU-Darwin%20Workstation/README.md) |
| Macintosh Soft | Warm pale Macintosh desktop with teal accents and flat readable controls | [Preview and installation](themes/Macintosh%20Soft/README.md) |
| Moonstone Stereo | Warm silver and sage hi-fi desktop with machined controls and instrument details | [Preview and installation](themes/Moonstone%20Stereo/README.md) |
| Ocean-Silk | Pale ocean desktop with teal accents and flat readable controls | [Preview and installation](themes/Ocean-Silk/README.md) |
| Plum Afterglow | Dark plum desktop with lavender accents and flat readable controls | [Preview and installation](themes/Plum%20Afterglow/README.md) |
| Dusk-Ribbons | Dusky slate desktop with rose accents and rounded workspace styling | [Preview and installation](themes/Dusk-Ribbons/README.md) |
| Quiet Sage | Quiet dark sage desktop with muted green accents and flat readable controls | [Preview and installation](themes/Quiet%20Sage/README.md) |

Each package contains Cinnamon shell styling, GTK 2/3/4 controls, Metacity window borders, a wallpaper and a menu logo. Install and select a theme manually using its README. The instructions refuse an existing same-name installation.

The seven original packages passed the recorded desktop checks and temporary-home installation/restoration rehearsals. Their previews show the exact tested themes with stock Cinnamon applets and system icons. Per-package acceptance records describe the tested environment, scope and evidence.

Fonts and GTK2 engines are external dependencies. Aqua additionally includes optional matching icons and a dock extension with its own setup instructions and acceptance record. Panel arrangements, cursor themes, custom widgets, application and terminal setups, and boot/login themes remain separate components.

Theme source retains its original GPL notices. Artwork has separate component terms; see each package’s LICENSING.md and SOURCE-NOTICES.md. GNU-Darwin Workstation has documented artwork terms. The other six are included at the repository owner’s explicit request with their original artwork source/grant records still unresolved. Repository submission is recorded separately from provenance verification.

GNU-Darwin Aqua has completed its Snow Leopard dock refinement and is included with scoped private-session verification. Its separate Apple wallpaper and period-icon provenance limitations are documented in the package; submission does not imply a third-party redistribution grant.

This is an independent collection, not an official Cinnamon Spices listing.
