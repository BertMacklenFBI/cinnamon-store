# GNU-Darwin Aqua icons

Period-style PNG assets are copied byte-for-byte from the pinned B00merang-Artwork/Mac-OS-X-Lion snapshot. The folder and file-browser shapes were visually compared with the Snow Leopard 10.6 references. The source collection's title is Lion, and these are not authenticated Apple-original files. Its repository provides no license file; redistribution permission is not asserted. This staged copy is for the user's local personal desktop request.

Modern application branding uses unchanged installed Papirus SVGs, with its license in PAPIRUS-COPYRIGHT. No background tile, recoloring or application renaming is applied. Other icons inherit from Papirus/hicolor. Each source path and hash is recorded in ../assets-report.json. Cursors remain unmodified Bibata.
