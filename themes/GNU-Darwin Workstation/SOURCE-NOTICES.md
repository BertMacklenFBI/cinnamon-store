Local palette/style/material changes remain separately identified by their exact source bytes; no upstream authorship is claimed. Source version is installed mint-themes 2.3.8. The official tag resolves to immutable commit `984fced9da446f90750421fda9a56ef0a5a5b881`; the retained COPYRIGHT matches that immutable upstream notice byte-exact. Original modified theme source is preserved as shipped CSS/XML/SVG files; source lineage and file hashes are recorded separately.
